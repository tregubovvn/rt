# 📝 Извлечение вопросов из XML-теста

Одностраничное HTML-приложение для извлечения всех вопросов из XML-файла теста на чтение 
(формат `<readingTest>`) с выводом последовательной нумерации, указанием фрагмента 
и правильных ответов.

Приложение полностью автономно: один HTML-файл, без серверной части, без зависимостей, 
без сборки. Работает офлайн в любом современном браузере.

## ✨ Возможности

| Функция | Описание |
|---|---|
| 📋 Извлечение вопросов | Все вопросы из всех фрагментов, сквозная нумерация |
| ✅ Правильные ответы | Выводятся в скобках после текста вопроса |
| 📄 Указание фрагмента | Вопросы группируются по фрагментам с заголовками `=== ФРАГМЕНТ N ===` |
| 📑 Название темы | Выводится из тега `<topicName>` первой строкой |
| 🔄 Два режима вывода | Только вопросы+ответы **или** текст фрагмента перед вопросами |
| 📥 Три способа загрузки | Вставка в поле, XML в URL, ссылка на файл в URL |
| 🔐 Пароль | Только для загрузки файла по ссылке из URL |
| 💬 Умная вставка | Ctrl+V обрабатывается автоматически, обычный текст вставляется как есть |
| ✏️ Защита правок | При переключении режима подтверждение, если поле редактировалось вручную |

## 🚀 Быстрый старт

1. Скачайте файл `index.html`.
2. Откройте его в браузере (двойной клик — сервер не нужен).
3. Вставьте XML в текстовое поле — результат появится автоматически.

> **Примечание:** для загрузки XML-файлов по ссылке (режим 3) страницу лучше открывать 
> через `http://`, а не `file://` — иначе браузер может заблокировать запрос (см. 
> [Известные ограничения](#-известные-ограничения)).

## 🖥 Интерфейс

Приложение состоит из:

- **одного текстового поля** — сюда вводится исходный XML и сюда же выводится результат;
- **трёх кнопок:**

| Кнопка | Действие |
|---|---|
| **Вставить** | Читает буфер обмена и обрабатывает содержимое как XML |
| **Копировать** | Копирует текущее содержимое поля в буфер обмена |
| **Показать / Скрыть текст фрагментов** | Переключает режим отображения (подробнее ниже) |

- **строки статуса** справа от кнопок — краткие сообщения о результате операции 
  (зелёным — успех, красным — ошибка), автоматически скрываются через 6 секунд.

## 📥 Режимы ввода XML

### 1. Вставка в текстовое поле

Основной режим, **пароль не требуется**.

- Нажмите кнопку **«Вставить»** или просто **Ctrl+V** в поле.
- Если вставленный текст похож на XML теста (содержит `<readingTest`, `<fragment` 
  или `<question`), он автоматически разбирается и заменяется готовым списком вопросов.
- Если текст не распознан как тест — он вставляется в поле без изменений, 
  в строке статуса появится предупреждение.

### 2. XML прямо в URL

XML (в URL-кодировке) передаётся параметром `xml`. **Пароль не требуется.**

```
index.html?xml=%3CreadingTest%3E%3CtopicName%3E...
```

Генерация ссылки в консоли браузера (F12):

```js
var xml = '<readingTest>...</readingTest>';
location.href = location.pathname + '?xml=' + encodeURIComponent(xml);
```

При открытии такой ссылки результат формируется сразу, без действий пользователя.

> ⚠️ **Важно:** XML обязательно кодируйте через `encodeURIComponent` — иначе символы 
> `<`, `>`, `&` сломают URL.
>
> ⚠️ **Длина URL ограничена** (~2000 символов в старых браузерах, десятки тысяч 
> в современных). Для больших тестов используйте режим 1 или 3.

### 3. Ссылка на XML-файл в URL (с паролем)

В параметре `xml` передаётся **ссылка** (`http://` или `https://`) на XML-файл. 
**Требуется пароль.**

```
index.html?pwd=1234&xml=https%3A%2F%2Fexample.com%2Ftest.xml
```

Генерация ссылки:

```js
location.href = location.pathname + '?pwd=1234&xml=' +
                encodeURIComponent('https://example.com/test.xml');
```

Поведение:

1. Если `pwd` указан и совпадает с вшитым паролем — файл загружается молча и сразу обрабатывается.
2. Если `pwd` не указан или неверный — пароль запрашивается через диалоговое окно 
   (до **3 попыток**). После отказа все попытки доступ блокируется до обновления страницы.
3. Загруженный файл разбирается; если вопросы не найдены, в поле выводится исходный текст файла.

## 🔐 Защита паролем

- Пароль **жёстко вшит в код** — константа `PASSWORD` в начале `<script>` (по умолчанию `1234`).
- Проверка — простое сравнение строк, без шифрования и хеширования.
- **Пароль нужен ТОЛЬКО** при загрузке XML-файла по ссылке из URL (режим 3). 
  Вставка XML в поле и XML прямо в URL работают без пароля.
- Пароль передаётся параметром `pwd` в открытом виде.

> ⚠️ **Защита символическая.** Пароль виден в исходном коде страницы (Ctrl+U) 
> и в самой ссылке. Не храните за ним что-либо ценное — это барьер от случайного доступа, 
> не более.

## 🔄 Режимы отображения

Кнопка **«Показать текст фрагментов»** переключает формат вывода **мгновенно**, 
без повторной вставки XML — разобранные данные хранятся в памяти страницы.

| Режим | Кнопка | Содержимое |
|---|---|---|
| Только вопросы (по умолчанию) | «Показать текст фрагментов» | Тема, фрагменты с вопросами и ответами |
| С текстом фрагментов | «Скрыть текст фрагментов» (подсвечена) | То же + полный текст каждого фрагмента перед его вопросами |

**Защита ручных правок:** если вы отредактировали результат в поле вручную, 
при переключении режима появится запрос подтверждения — перегенерировать текст 
из последнего XML или сохранить ваши правки.

## 📄 Формат входного XML

```xml
<readingTest>
    <topicName>Название темы</topicName>

    <fragment timeExcellent="30" timeGood="60">
        <text>Текст фрагмента для чтения.</text>
        <questions>
            <!-- Вопрос с выбором ответа -->
            <question type="choice">
                <text>Текст вопроса</text>
                <options>
                    <option>Неправильный вариант</option>
                    <option correct="true">Правильный вариант</option>
                    <option>Еще один неправильный</option>
                </options>
            </question>

            <!-- Вопрос со свободным вводом -->
            <question type="input">
                <text>Напишите точный ответ.</text>
                <answer>ключевое_слово</answer>
            </question>
        </questions>
    </fragment>
</readingTest>
```

### Извлекаемые данные

| Элемент | Как обрабатывается |
|---|---|
| `<topicName>` | Выводится первой строкой: `ТЕМА: ...` |
| `<fragment>` | Формирует заголовок `=== ФРАГМЕНТ N ===` (нумерация с 1) |
| `<fragment><text>` | Текст фрагмента (выводится только в режиме «с текстом») |
| `<question type="choice">` | Правильный ответ — текст `<option>` с атрибутом `correct="true"` |
| `<question type="input">` | Правильный ответ — содержимое тега `<answer>` |

### Особенности распознавания

- Принимаются варианты атрибута: `correct="true"`, `"1"`, `"yes"`, `"да"` (без учёта регистра).
- Если правильных вариантов несколько — все выводятся через разделитель ` / `.
- Тип вопроса определяется по атрибуту `type`; неизвестный тип или отсутствующий ответ 
  помечаются как `(ответ не найден)`.
- Атрибуты `timeExcellent` / `timeGood` в вывод не попадают.

## 📤 Примеры вывода

### Режим «только вопросы и ответы»

```
ТЕМА: Название темы

=== ФРАГМЕНТ 1 ===
1. Текст вопроса (Правильный вариант)
2. Напишите точный ответ (указывай количество слов в ответе). (ключевое_слово)

=== ФРАГМЕНТ 2 ===
3. Вопрос из второго фрагмента (Правильный вариант 2)
```

### Режим «с текстом фрагментов»

```
ТЕМА: Название темы

=== ФРАГМЕНТ 1 ===
Текст первого фрагмента для чтения. Рекомендуемый объем – один абзац.

1. Текст вопроса (Правильный вариант)
2. Напишите точный ответ (указывай количество слов в ответе). (ключевое_слово)

=== ФРАГМЕНТ 2 ===
Текст второго фрагмента...

3. Вопрос из второго фрагмента (Правильный вариант 2)
```

Нумерация вопросов — **сквозная по всему тесту**.

## 🔧 Технические детали

- **Стек:** чистые HTML5 + CSS + vanilla JavaScript (ES5-совместимый синтаксис). 
  Никаких фреймворков и внешних библиотек.
- **Разбор XML** — штатный `DOMParser` браузера; некорректный XML отбраковывается 
  по наличию `<parsererror>`.
- **Буфер обмена** — `navigator.clipboard` с автоматическим откатом на 
  `document.execCommand('copy')`, если API недоступен или запрещён браузером.
- **Загрузка файла по ссылке** — `XMLHttpRequest` GET-запросом.
- **Хранение состояния** — разобранный XML кэшируется в памяти (`lastData`), 
  что позволяет мгновенно переключать режимы отображения.

## ⚠️ Известные ограничения

| Ограничение | Причина | Обход |
|---|---|---|
| Кнопка «Вставить» может не сработать | Браузеры разрешают чтение буфера только по HTTPS или при разрешении пользователя | Используйте **Ctrl+V** — автообработка работает всегда |
| Загрузка по ссылке блокируется при `file://` | Политика CORS браузеров | Разместите HTML и XML на одном сервере и открывайте через `http://` |
| Загрузка по ссылке с чужого домена блокируется | CORS: сервер XML должен отдавать заголовок `Access-Control-Allow-Origin` | Храните XML рядом с HTML или настройте CORS на сервере |
| Большие XML не помещаются в URL | Ограничение длины URL | Используйте вставку в поле (режим 1) |
| Пароль виден в коде страницы | Клиентская проверка в JS | Осознанное решение — защита символическая |
| Некорректный XML не обрабатывается | Строгий XML-парсер браузера | Проверьте синтаксис: закрытые теги, экранированные `&`, `<`, `>` |
